# Repo-specific notes

This repo is normally regenerated/pushed automatically by `ActualNews`'s
`Automator.py` pipeline (see the `Auto update ...` commits). Files like
`static/BaseStyle.css` aren't generated by that pipeline, though, so they
get edited and pushed here directly from time to time.

## Git identity
Never commit using the maintainer's private email address. Use the GitHub
noreply alias instead, matching existing commit history:

    LuisMeister <131911554+LuisMeister@users.noreply.github.com>

Set `GIT_AUTHOR_NAME`/`GIT_AUTHOR_EMAIL`/`GIT_COMMITTER_NAME`/
`GIT_COMMITTER_EMAIL` as env vars on the commit command itself rather than
writing to git config. When pushing, pass a token-embedded URL directly to
`git push` rather than storing it in `.git/config` (a `git clone` with a
token embedded in the URL does persist it into `.git/config` -- run
`git remote set-url origin https://github.com/<owner>/<repo>.git` right
after cloning to strip it back out).

## Commit messages: this repo is public
`ActualNews` (the scraping/classification/tiering pipeline) is private
precisely because that logic is the maintainer's IP -- don't undercut that
by describing it here. When committing to this repo, write messages about
*this repo's own files* only. Don't name `ActualNews`'s private script
files (`Accumulator.py`, `WebsiteBackend.py`, `Eliminator.py`, etc.) or
explain what their internal logic does -- a short "matches ActualNews
commit <sha>" is fine for cross-repo context, but leave it at that.
